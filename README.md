# Склон — горнолыжная школа в Красной Поляне

Три варианта дизайна нового сайта. Общий контент, цены и фотографии — разный характер подачи.

| Ссылка | Вариант | Характер |
| --- | --- | --- |
| `/` | Выбор варианта | Служебная страница со всеми тремя версиями |
| `/v1/` | «Вертикаль» | Тёмный кинематографичный, Unbounded + Onest, оранжевый акцент |
| `/v2/` | «Свет» | Светлый редакционный, Literata + Onest, бирюзовый акцент |
| `/v3/` | «Ясность» | Сервисный: калькулятор стоимости, сравнение программ, Golos Text |

## Технически

- Статический HTML + CSS + JS, без сборки и зависимостей.
- Шрифты self-hosted, подрезаны по используемым символам.
- Изображения в AVIF/WebP с JPEG-фолбэком, адаптивные `srcset`.
- Формы пока визуальные: отправка подключается отдельно. Рабочие ссылки — `tel:`.
- Цены переключаются по сезонам через `data-s` / `data-h` / `data-p`.

## Локальный запуск

```bash
python -m http.server 8123
```

Открыть `http://127.0.0.1:8123/`.

## Структура

```
index.html        — страница выбора вариантов
v1/ v2/ v3/       — отдельные версии (index.html, style.css, main.js)
assets/img/       — общие оптимизированные фотографии и логотипы
assets/fonts/     — self-hosted woff2
```
